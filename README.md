# GOE 메신저 캘린더

GOE 메신저에서 받은 쪽지와 첨부를 한곳에서 보고, 업무와 마감일을 월 달력에 정리하는 Windows 앱입니다. 개인이 만든 비공식 도구입니다.

이 저장소는 **배포판(릴리스)만** 올리는 곳입니다. 소스 코드와 자세한 설명은 [rndosd/brity-assistant-public](https://github.com/rndosd/brity-assistant-public)에 있습니다.

### ⬇️ [최신 판 내려받기 (Releases)](https://github.com/rndosd/goe-messenger-calendar/releases/latest)

릴리스에서 **`goe-messenger-calendar-windows-x64-<판>.zip`** 을 받아 쓰기 가능한 폴더에 전체 압축 풀기한 뒤 **GOE Messenger Calendar.exe**를 실행하세요. 이미 쓰고 있다면 앱 머리줄의 **업데이트**를 누르면 됩니다.
