# GOE 메신저 캘린더

GOE 메신저에서 받은 쪽지와 첨부를 한곳에서 보고, 업무와 마감일을 월 달력에 정리하는 Windows 앱입니다. 개인이 만든 비공식 도구입니다.

## ⬇️ GOE 메신저용은 여기서 받으세요

### [최신 판 내려받기 (Releases)](https://github.com/rndosd/goe-messenger-calendar/releases/latest)

1. 위 링크에서 **`goe-messenger-calendar-windows-x64-<판>.zip`** 하나만 받습니다.
2. 받은 ZIP을 쓰기 가능한 폴더에 **전체 압축 풀기**합니다.
3. **GOE Messenger Calendar.exe**를 실행합니다. 가상 자료로 먼저 둘러보려면 **GOE Messenger Calendar Sample.exe**를 여세요.

이미 쓰고 있다면 받을 필요 없이 앱 머리줄의 **업데이트**를 누르면 됩니다.

릴리스 페이지의 **Source code**, 패치 ZIP, `update-goe.json`은 받지 않아도 됩니다.
